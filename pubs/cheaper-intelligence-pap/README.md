# Pre-analysis plan: empirical companion to "Will Cheaper Machine Intelligence Raise Employment?"

Gökhan Mergen. Version 1.2, frozen October 13, 2026.

This folder time-stamps the pre-analysis plan for the empirical companion to the
[working paper](../cheaper-intelligence/cheaper-intelligence.pdf). The plan was
frozen before any of its estimation was run: no project 1 first stage, no scoring
of post-2019 O\*NET tasks, and no post-period ACS microdata. The commit that adds
this folder is its public timestamp.
