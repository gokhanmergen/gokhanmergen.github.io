# BEYOND THE COPPER — a two-disk megademo by "Neon Blitter"

A love letter to Amiga cracktros, demos, games and tracker music, pushed to places a 7 MHz 68000 could
only dream of. Pure HTML + WebGL2 + Web Audio: no build step, no dependencies, no external assets.
Every pixel, glyph and sample (including seven minutes of music) is generated by code at load time.

**The idea in one line:** every part shows an Amiga icon *exactly as it was* (320×256, 12-bit colour,
50 Hz, inside a CRT), then a **raster beam sweeps down the screen** and the very same thing carries on
at the fidelity of a modern GPU.

The sound goes through the beam too: while the picture is still 1985 the music plays as if from an A500
(8-bit, 22 kHz, the LED filter), and the filter opens as the line passes. Most parts use the plain sweep;
three bend it: in Boing it stops halfway for a bar (a copper split), in Glenz the crystal refracts it, and
in the Tunnel it runs down the tunnel as a ring.

Between parts the wide modern picture closes back into the tube, so the next part's 1985 picture appears
in the same glass: the beam goes one way, the tube the other.

A scene-by-scene breakdown with timings, motivation and known weaknesses is in [`scenario.md`](scenario.md).
The latest findings, fixes and remaining art-fidelity gaps are in [`REVIEW.md`](REVIEW.md).

## Run it
Open `index.html` in a recent Chrome / Edge / Firefox / Safari (double-click works, no server needed).
Wait for the Disk 1 soundtrack to "depack" (~5 s), click, and turn the sound up. Headphones recommended.
Disk 2's soundtrack depacks in the background while Disk 1 plays; if you jump ahead before it is ready,
the "PLEASE INSERT DISK 2" screen waits and shows its progress. Total runtime ≈ 7:10.

| Key | Action |
|-----|--------|
| `Space` | pause / resume |
| `←` / `→` | previous / next part (the part's name appears on screen) |
| `1` / `2` | jump to Disk 1 / Disk 2 (`Home` also restarts) |
| `F` or double-click | fullscreen |
| `H` | stats overlay (fps, render scale, pattern/row or bar/BPM) |
| `Q` | quality: auto → 100% → 75% → 50% |

`index.html?t=120` starts at 120 s (it plays once you click). Disk 2 starts at 192.5 s.

## Disk 2: the games — "LEYENDA"
Music: Isaac Albéniz, *Asturias (Leyenda)*, 1892 (public domain), played on a modelled nylon-string guitar.
The frame: *Leyenda* is a game that never existed. Each section of the piece is a level in a different
classic Amiga game genre, and the music plays the game: the notes are the joystick.
Procedural game art takes visual cues from Prince of Persia, Project-X and Lotus Esprit Turbo Challenge;
no original game assets are bundled. The final computer is an A1200-inspired procedural model.

| Time | Part | Genre | What the notes do |
|------|------|-------|-------------------|
| 3:12 | Disk change | "PLEASE INSERT DISK 2" | drive clicks, decrunch |
| 3:19 | Paula tracker | a four-channel tracker playing the opening on 8-bit Paula | the real notes scroll by |
| 3:30 | Level 1: Run | multi-layer parallax action game at dusk | a footfall on every beat of the thumb melody, a leap every second bar |
| 3:52 | Level 2: The Floor of Stars | vertical shoot-'em-up over star tiles | every pluck fires a shot, every accented chord is a smart bomb; the floor takes the colour of the harmony |
| 4:24 | Level 3: The Road to the Fiesta | night road racer | one lamp post per beat, one firework per kick, the palace on the climax chord |
| 4:44 | Copla | letterboxed adventure-game cutscene: a moonlit courtyard | every melody note is a droplet that rings in the pool |
| 5:45 | Bonus stage: Pinball | flamenco pinball table | the ball strikes a bumper on every accented chord |
| 6:18 | Dawn | the ending: the courtyard at sunrise | end credits in the 8×8 font; lanterns go out on the timpani |
| 6:52 | Finale | the machine itself, seen from outside for the first time | the tracker plays the last bars on its monitor; THE END; someone switches it off |

The tune comes from `../amiga_gemini`'s guitar tab, fixed: exact triplet timing (24 ticks per beat), the
opening ostinato restored to p-i-m triplets, one 4-beat bar corrected, drums written for 3/4, a tempo map
(132 BPM A section, 96 BPM copla, ritardando coda), and an extended Karplus-Strong nylon guitar where each
string rings until it is plucked again (tuning measured within 0.5 cent).

## The music engine
`js/music.js` is a tiny offline "tracker". Chip sections emulate Paula: four hard-panned voices, 8-bit
32-sample wavetables, nearest-neighbour playback with sample-and-hold, and the classic `0xy` arpeggio,
`3xx` portamento and `4xy` vibrato effects. The modern sections add supersaws, resonant filters, sidechain
pumping, a Freeverb-style stereo reverb and a ping-pong delay. Visuals sync to the actual note events
(`MUSIC.SYNC`, `LEY.plucks`, `LEY.chords`, `LEY.melody`), not to an audio analyser.

The last stage of both disks' render is the Paula chain (`paulaGen`): the mastered mix is held at 22 kHz
without anti-aliasing, cut to 8 bits and low-passed at 3.6 kHz, crossfaded by a curve that `main.js` builds
from each part's `beamAt()` (the same function the picture uses), so the sound opens exactly with the beam.

## Files
- `js/boing_physics.js`: deterministic sphere collisions for the modern Boing scene
- `js/gfx.js`: WebGL2 helpers and the post chain (bloom, ACES, CRT, the raster-beam transition, part labels)
- `js/pix.js`: the "1985 side": a 320×256 12-bit software framebuffer, 8×8 bitmap font, Scale2x demo fonts, sprites, dithering
- `js/music.js`: synth + instruments, Disk 1 song, resumable offline renderer, sync helpers
- `js/leyenda_tab.js`, `js/leyenda.js`: Disk 2 note data (one line per bar) and its arrangement
- `js/scene_*.js`: one file per part
- `js/main.js`: loader, two-disk audio clock, timeline, adaptive resolution, keys

## Developer hooks
- `index.html?still=<seconds>` renders one frozen moment without audio (`&run=1` lets time advance;
  `window.__t = <seconds>` seeks; `await __bench()` returns GPU milliseconds per frame).
- `&only=run,shmup` initialises just the scenes whose name contains one of the keys.
- Shader rule learned the hard way: Metal's compiler inlines every call, so a heavy GLSL function called
  from several nested call sites can take minutes to compile. Keep each heavy function to one call site
  (loop over the rays instead).

## Regression checks

Run `node --test tests/*.test.cjs` (Node.js 18+) for playback, sphere-contact and Paula-chain checks.
